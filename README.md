# Valentines 💖

A romantic, interactive web application designed for a special Valentine's Day proposal. This project features animations, interactive buttons, and a personalized journey for your special someone.

## ✨ Features

- **Anniversary Login:** A lock screen that requires a special date to proceed.
- **Photo Slideshow:** Displays a rotating gallery of your favorite memories.
- **Playful Interaction:** A "No" button that runs away when hovered over, ensuring a "Yes"!
- **Kiss Counter:** A fun interactive button to collect kisses and unlock a secret message.
- **Celebration:** Confetti explosions and sweet messages upon saying "Yes".
- **Love Letter:** A heartfelt personal message section.
- **Animated Garden:** A beautiful CSS-animated tulip garden finale.
- **Background Music:** Sets the mood with romantic audio.

## 🚀 How to Use

1. **Clone or Download** this repository.
2. **Add Your Photos:**
   - Place your images in the project folder.
   - Rename them to `rooi.jpg`, `photo2.jpg`, `photo3.jpg` or update the `PHOTOS` array in `script.js`.
3. **Customize the Date:**
   - Open `script.js` and update `const ANNIVERSARY_DATE = "2022-08-02";` to your special date.
4. **Personalize the Letter:**
   - Open `index.html` and edit the text inside the `#letterScreen` div to write your own message.
5. **Run:**
   - Simply open `index.html` in any modern web browser.

## 📂 File Structure

- `index.html`: The main structure of the page.
- `style.css`: Styling for glassmorphism, animations, and layout.
- `script.js`: Logic for interactions, slideshows, and animations.
- `README.md`: This file.

## 🛠️ Technologies Used

- HTML5, CSS3, JavaScript
- SweetAlert2 for beautiful popups.
- Canvas Confetti for celebration effects.
